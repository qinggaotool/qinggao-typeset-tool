## 功能特性

- **一键论文排版**：围绕 Word 工作，按论文格式要求一键调整段落、行距、标题层级等格式，无需手动逐项设置。
- **截图挂起来**：截图后挂起，用时直接拖到 Word / 聊天框，也可贴在桌面上备用。
- **文字挂起来**：复制文字后挂起，用时拖到 Word / 聊天框，减少来回切换窗口。
- **本地运行**：文档在本机处理，不上传到云端服务器，降低论文外泄风险。
- **免安装源码式使用**：下载 Release 中的安装包即可运行，无需编译。

## 适用环境与兼容说明

- 需要电脑已安装 **Microsoft Word**，工具在 Word 旁配合使用。
- 本工具仅做**格式排版与效率辅助**，不提供论文降重、查重或代写服务。
- 不同学校、专业的格式要求存在差异，排版后请对照本校最新论文格式规范人工复核一遍。
- 如使用 WPS 或其他版本 Office，个别排版项可能存在兼容差异，以实际效果为准。

## 使用说明（简述）

1. 在 Releases 下载并运行 `v2.0.18.exe`。
2. 打开需要排版的 Word 文档。
3. 在工具中选择对应排版功能，按提示完成格式调整。
4. 排版后通读检查目录、页码、参考文献等细节，确认符合要求后再保存提交。
